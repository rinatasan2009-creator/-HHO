# -HHO
Проект исследует потенциал применения водородных генераторов (HHO/газ Брауна) в системах отопления вместо автомобильного сектора. Анализируются данные по повышению теплового КПД котлов за счет более полного сгорания топлива и снижению вредных выбросов. Особое внимание уделено экономической целесообразности и внешним источникам питания.
